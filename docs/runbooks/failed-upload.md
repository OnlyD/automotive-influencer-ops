# Failed upload

## Symptoms

Media intake rejects a file or narration is missing.

## Diagnosis

Check actual format/streams, duration, dimensions, size (maximum 2 GB), readable local path and rights evidence. The local bridge cannot access another machine automatically.

## Safe action

Request a supported original or the separate voice track. Ingest a new immutable copy; never rename arbitrary data to fake a MIME type. Remote signed uploads await authorized cloud setup.

## Preserve

Original recordings, registered successful copies and existing hashes.

## Closure

The copied original probes successfully, hashes match and its production association is correct.
