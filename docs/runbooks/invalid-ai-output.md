# Invalid ai output

## Symptoms

Schema, semantic validation or reviewed workflow fingerprint fails.

## Diagnosis

Identify the exact workflow/version, changed definition file and typed validation error. Check source/scene references and locked fields.

## Safe action

Reject the candidate. Correct and review the versioned definition or supplied candidate; update reviewed fingerprints only through an authorized technical change. Do not officialize an unvalidated draft.

## Preserve

Original input/output evidence, source links and earlier versions.

## Closure

The corrected candidate validates and still requires the proper human approvals.
