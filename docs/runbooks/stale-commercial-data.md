# Stale commercial data

## Symptoms

Preparation/publication is blocked by expired, missing or prior-day commercial confirmation.

## Diagnosis

Compare exact script version, offer eligibility, availability, source evidence, confirmation timestamp and validity. Local publication-day checks use UTC.

## Safe action

Obtain actual confirmation. Register a new script version with refreshed metadata/terms; review factual, creative and commercial gates and its dependent media/packages. Re-register unchanged reviewed media against the new script when appropriate.

## Preserve

Old offer evidence, approved versions and already published receipts.

## Closure

Current-day unexpired conditions and all exact-version publication gates pass.
