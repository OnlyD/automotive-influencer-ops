# Presenter script preview

Version `1.1.0` creates a Spanish, non-publishable script preview from source-linked candidate facts. It selects two or three facts that fit the audience and editorial angle without becoming a specification dump. If fewer than two usable facts are supplied, it uses what is supported and warns about the limited research. Every factual line retains candidate fact and source references. The output is not a verified fact set or production artifact and requires technical-operator review.
