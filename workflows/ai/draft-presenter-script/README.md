# Presenter script preview

Version `1.2.0` creates a Spanish, non-publishable script preview from source-linked candidate facts researched in the same presenter conversation. It selects two or three facts that fit the audience and editorial angle without becoming a specification dump. If fewer than two usable facts are supplied, it uses what is supported and warns about the limited research. Every factual line retains candidate fact and source references. The closing CTA invites contact (with a placeholder when no method was supplied) and following, liking, and commenting. The output is not a verified fact set or production artifact and requires technical-operator review.
