# AI workflows

Implemented workflows must have a versioned manifest, schemas, templates, prompt, fictional examples, and tests. The local AI Runner registers only `research-vehicle@1.0.0`, `validate-vehicle-data@1.0.0`, `draft-vehicle-script@1.0.0`, `draft-presenter-script@1.0.0`, and `draft-promotional-script@1.0.0`. Arbitrary prompts and commands are not supported. Promotional scripts keep missing same-day terms as visible in-script placeholders and always require commercial review. Each output remains subject to the approval gate declared in its manifest.
