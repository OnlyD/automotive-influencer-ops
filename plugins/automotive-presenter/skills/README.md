# Presenter skills

Technical implementation instructions in this directory use English. Every interaction and output presented to the influencer must always be in Spanish. The technical operator does not use the presenter's onboarding or update skills for technical work. The presenter's standard order is `actualizar-influencer`, `investigar-vehiculo` in the same conversation, then either `generar-guion-promocional` (the priority path) or `generar-guion` (detailed review). Research and script writing remain separate skills. Both script skills select source-linked vehicle facts and include contact plus follow/like/comment CTAs; they provide a human-readable Spanish Word draft and never present internal JSON or schemas.
