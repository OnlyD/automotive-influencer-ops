# Presenter skills

Technical implementation instructions in this directory use English. Every interaction and output presented to the influencer must always be in Spanish. The technical operator does not use the presenter's onboarding or update skills for technical work. `actualizar-influencer` refreshes presenter tools and establishes presenter context; it can create new defect reports under the dedicated feedback directory after review. The presenter has two script skills: `generar-guion` for detailed reviews from the operator's research handoff, using two or three relevant source-linked facts, and `generar-guion-promocional` for sales drafts combining two or three attractive research facts with separate offer information. Both provide a human-readable Spanish Word draft; internal JSON and schemas are never presented.
