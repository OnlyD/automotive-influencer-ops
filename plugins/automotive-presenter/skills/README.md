# Presenter skills

Technical implementation instructions in this directory use English. Every interaction and output presented to the influencer must always be in Spanish. The technical operator does not use the presenter's onboarding or update skills for technical work. `actualizar-influencer` refreshes presenter tools and establishes presenter context; it can create new defect reports under the dedicated feedback directory after review. `generar-guion-promocional` makes promotional drafts with in-script placeholders for missing terms and validity. `generar-guion` creates only a source-linked, non-official detailed-script preview that requires technical review.
