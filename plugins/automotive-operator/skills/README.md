# Operator skills

Technical skills for inventory, research, and operations. Operator-facing technical interaction uses English. Influencer-facing content remains Spanish. `actualizar-tecnico` is the operator's role and tool-update entry point. `investigar-vehiculo` produces a source-linked research bundle and a separate Spanish handoff for the presenter's detailed-review script skill. Script generation remains available as a registered workflow; there is no generic operator-facing script-generation skill.
